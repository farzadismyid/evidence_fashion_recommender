# Archived material

This directory holds superseded development material that is intentionally excluded from the
active final-run pipeline. It is retained for historical reference only.

- `archive/` contains the prior archived repository snapshot.
- `calibration/` contains the deferred human-calibration materials.
- `configs/`, `data/`, `docs/`, `scripts/`, `src/`, and `tests/` contain superseded variants and
  one-off post-run utilities.

The active experiment is defined by the root `configs/`, `data/kb/fashion_rules.csv`, `src/`,
`scripts/`, `tests/`, `artifacts/`, `paper/`, and `thesis/` directories.
